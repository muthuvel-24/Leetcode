# 🧠 LeetCode — DSA Practice in Java

> My personal collection of LeetCode solutions, maintained to improve problem-solving, algorithm selection, and time/space complexity analysis.

## 🎯 Goal

The focus of this repository is not only solving problems, but learning how to move from a brute-force solution to a more efficient approach.

### My approach

```text
Understand the problem
        ↓
Build a brute-force idea
        ↓
Analyze time & space complexity
        ↓
Identify the bottleneck
        ↓
Choose an optimized technique
        ↓
Implement + test edge cases
```

| Pattern | Example | Typical Use |

| Dynamic Programming | Climbing Stairs | Overlapping subproblems |

## 📊 Complexity Mindset

For every solution, I try to understand:

- **Time Complexity** — how runtime grows with input size
- **Space Complexity** — additional memory used
- Whether the solution can be optimized
- Why a particular data structure or algorithm is appropriate
